# Anvexa

A responsive, single-page website and illustrative client portal prototype for Anvexa.

## Run locally

Open `index.html` in a browser. The site uses only the included `Anvexa.png` asset and has no build step.

## Publish with GitHub Pages

1. Push the repository to GitHub.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for the Pages deployment to finish. The site will be available at `https://<owner>.github.io/anvexa/`.

## Prototype notes

The client portal, cloud figures, reports, and security status are illustrative demo content, not live service data. The support form does not send or store submissions. Connect real services and replace sample content before using this as a production service.
